# Hand derivation vs. object-oriented MBS assembly (slider-crank notebook)

Notebook `slider_crank_hand_vs_mbs.ipynb` (generated by `build_notebook.py --execute`; sympy, numpy, scipy, matplotlib). Created 2026-10-31.

**Question:** How does assembling Body / Revolute / Prismatic / force objects reproduce the equation of motion derived by hand?

## Structure
- **A, hand route:** loop closure, velocity coefficients dq/dθ, per-body kinetic energy, then M(θ)θ̈ + ½M'θ̇² = Q.
- **B, MBS objects:** each body gives (x, y, φ) and diag(m, m, J); each joint gives Φ rows; force elements give (∂r_P/∂q)ᵀf; `Model.assemble()` stacks them into the DAE [M Φqᵀ; Φq 0][q̈; λ] = [F; γ].
- **C, the bridge, using only the assembled matrices:**
  - Newton on Φ = 0 reproduces the loop closure.
  - B = null(Φq) gives the velocity coefficients (Kane's partial velocities).
  - BᵀMB = M(θ), body by body.
  - BᵀM·a_p from γ = ½M'θ̇².
  - BᵀF = Q, and BᵀΦqᵀ = 0, so the reactions drop out.
- **D, simulation:** coasting from 9500 rpm; the hand ODE and the DAE agree (difference about 1e-9 rad). Constraint drift at rtol 1e-5 over 0.2 s: 0.6 mm unstabilised, sub-µm with Baumgarte. The joint forces λ pass a whole-mechanism Newton check against hand kinematics.
- **E, extension:** gravity and a gas spring take two objects in the MBS route but need re-derivation by hand; the routes still agree.
- **F:** summary table, where Adams, Simpack, Dymola and Kane/pycamtrain sit, and exercises (desaxé offset, switching the independent coordinate near TDC, flexible main bearing, second cylinder).

All checks agree to 1e-9 or better, and the symbolic differences are zero.
